# DevDigest API

# 🔥 DevDigest API — Асинхронный Агрегатор IT-Новостей с Хайп-Скорингом

Высокопроизводительное асинхронное бэкенд-приложение на **FastAPI**, спроектированное для автоматического сбора, анализа и персонализированной выдачи IT-трендов на основе подписок пользователей. 

Проект полностью контейнеризирован с помощью **Docker** и использует продвинутую архитектуру фоновых воркеров (**Celery + Redis**).

## 🚀 Киллер-фичи проекта
*   **Полная асинхронность:** Архитектура построена на неблокирующем вводе-выводе (`FastAPI` + `SQLAlchemy 2.0` + `asyncpg` + `httpx`).
*   **Фоновый парсинг по расписанию:** Сервис `Celery Beat` каждый час инициирует асинхронный сбор топ-30 новостей с официального HackerNews API.
*   **Алгоритм Хайп-Скоринга:** Каждая статья оценивается фоновым воркером на основе её рейтинга (Score) и времени публикации, отсеивая спам.
*   **Безопасность (OAuth2 + JWT):** Пароли пользователей надёжно хэшируются с использованием `passlib[bcrypt]`. Доступ к персональной ленте защищён валидацией JWT-токенов.
*   **Автоматический Сидинг (Lifespan):** База данных при первом старте сама наполняется дефолтными IT-тегами с помощью встроенных событий жизненного цикла FastAPI.
*   **Профессиональные миграции:** Структура таблиц (включая связи Многие-ко-Многим) версионируется асинхронным `Alembic`.

## 🛠️ Технологический стек
*   **Framework:** FastAPI (Python 3.12)
*   **Database:** PostgreSQL 15 + SQLAlchemy 2.0 (ORM) + Alembic (Миграции)
*   **Task Queue:** Celery + Redis (Брокер сообщений) + Celery Beat (Планировщик задач)
*   **HTTP Client:** HTTPX (Асинхронный сбор данных)
*   **Security:** PyJWT + Passlib (Bcrypt) + OAuth2 Password Bearer Flow
*   **DevOps:** Docker + Docker Compose (Мультиконтейнерная сборка)

## 🏗️ Архитектурная структура папок
```text
devdigest-api/
├── alembic/              # Скрипты и версионирование миграций БД
├── app/                  # Изолированное ядро Python-приложения
│   ├── api/              # HTTP-контроллеры (Роутеры users, tags, articles)
│   │   └── deps.py       # Dependency Injection (get_current_user для JWT)
│   ├── core/             # Глобальные конфиги Pydantic и сессия SQLAlchemy
│   ├── models/           # Единый файл описания декларативных моделей БД
│   ├── schemas/          # Схемы валидации данных Pydantic v2 (DTO)
│   ├── services/         # Сервисный слой (Бизнес-логика и CRUD запросы)
│   ├── tasks/            # Фоновые процессы (Celery worker и асинхронный парсер)
│   └── main.py           # Точка входа приложения & FastAPI Lifespan 이벤트
├── .env                  # Конфигурация переменных окружения (пароли, хосты)
├── alembic.ini           # Конфигурация Alembic
├── docker-compose.yml    # Инфраструктурный манифест (5 связанных сервисов)
└── Dockerfile            # Инструкция многоэтапной сборки Python-окружения
```

## ⚡ Быстрый запуск (Развёртывание инфраструктуры)

1. Клонируйте репозиторий и перейдите в корень:
   ```bash
   git clone https://github.com
   cd DevDigestAPI
   ```
2. Создайте файл `.env` в корне и заполните доступы:
   ```text
   POSTGRES_USER=postgres
   POSTGRES_PASSWORD=postgres
   POSTGRES_DB=devdigest
   POSTGRES_HOST=postgres
   POSTGRES_PORT=5432
   REDIS_HOST=redis
   REDIS_PORT=6379
   SECRET_KEY=your_super_secret_jwt_key_32_characters_long
   ALGORITHM=HS256
   ACCESS_TOKEN_EXPIRE_MINUTES=60
   ```
3. Запустите всю экосистему одной командой:
   ```bash
   docker compose up -d --build
   ```
4. Накатите структуру таблиц в пустую базу данных PostgreSQL:
   ```bash
   docker compose run --rm api alembic upgrade head
   ```

## 🌐 Использование и Эндпоинты
После запуска интерактивная документация Swagger доступна по адресу: `http://localhost:8000/docs`

*   `POST /users/register` — Регистрация аккаунта.
*   `POST /users/login` — Авторизация (выдача JWT-токена). После ввода данных в Swagger активируется **кнопка с замочком** 🔒 для защищённых запросов.
*   `GET /tags` — Просмотр доступных тегов (генерируются автоматически на старте).
*   `POST /tags/subscribe/{tag_id}` — Подписка на технологию (например, Python или AI).
*   `GET /articles/feed` — **Ваша персональная хайп-лента**. Выдаёт статьи только по вашим подпискам, отсортированные по рейтингу популярности.
